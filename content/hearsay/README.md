# Hear Say content

`scenes.json` is derived from the Hear Say prompt and video metadata in the user's local Party Pack 11 installation. The user states they have written permission to redistribute Hear Say media in this public project. Jackbox Games retains ownership of its original content; this repository does not grant third parties a license to reuse it.

The JSON maps each prompt to its source video and exact recording slot durations. Converted video and audio files are being prepared separately and are not yet published in this directory.
